### 6. 遇到：git 代理配置指向已关闭的端口

首次 `git ls-remote` 报：
```
Failed to connect to 127.0.0.1 port 7897 after 0 ms: Couldn't connect to server
```
排查：`nc -z 127.0.0.1 7897` → **关闭**；`git config --get http.proxy` → 配了 7897；
但 `curl https://github.com` → **200（直连可用）**。

处理：用 `-c` 对**本次命令**覆盖，不改全局配置：
```
git -c http.proxy= -c https.proxy= push origin main
```
推送成功。
