它只做一件事，但做到底

不是「又一个标签管理器」

目标是把当前窗口保存成可找回、可恢复的工作现场。保存、找回、恢复三个动作构成完整闭环，不掺别的。

01 / SAVE

一键把整个窗口收成会话

扩展图标、工具栏按钮、快捷键、右键菜单四条入口走同一条保存链路。保存后当前窗口标签随之关闭，屏幕立刻干净。可配是否保留固定标签。

02 / FIND

搜得到，才叫真的存住了

会话名、标签标题、网址三字段全文检索，多档权重排序、命中词高亮，再按域名、固定标签、保存时间筛选。上千会话里也能翻出三周前那一屏。

03 / RESTORE

整组展开，不打乱手头的事

一键在新窗口恢复整个会话；也可就地打开。未锁定会话恢复后自动从列表移除；锁定会话保留、可反复用。单个标签点开继续浏览时即从会话移除（锁定会话除外）。

功能细节

重度浏览器用户会用到的那部分

⌕

三字段全文检索

会话名、标题、网址都能搜，按会话归组再展开命中标签，可只恢复其中一条。

⚿

锁定会话

锁定的会话恢复后不消失、不被清理误伤。它是「收藏夹」与「剪切」的分界线。

⧉

清理重复标签

同一网址散在多个会话里时一键清理，每组保留最近一条，顺带收走空会话。锁定自动豁免。

⇅

导入导出不锁人

OneTab 文本双向互通 + JSON 全量备份。导入会如实报告「共 N 个、成功 X 个、跳过 Y 个」。

☰

拖拽排序 + 键盘重排

会话内标签可跨会话拖拽，也支持 ↑↓ / Home / End 键盘整理，折叠与相对时间帮你定位。

⌨

右键与快捷键

不打开管理页也能存：右键「保存当前 / 其他标签」。Ctrl+Shift+S 开管理器，Alt+Shift+S 存全部，Alt+S 存当前页。

数据去哪，你选

唯一的同步路径：你自己的云盘

不设账户、没有我们的服务器。数据默认只留在浏览器本地；要跨设备找回时，同步到你自己的 WebDAV 云盘。

唯一同步路径

你的 WebDAV 云盘

同步到你自己的云盘（坚果云、自建 Nextcloud 等），不经过我们的服务器。离开浏览器前用你的口令加密，口令只在内存、不落盘；地址默认预填坚果云。

  • ✓PBKDF2-SHA256 250k + AES-256-GCM，条件写防并发覆盖
  • ✓口令无法找回——忘了就得重新开始，这一点提前说清楚
  • ✓目录清单为明文（可见数量与修改时间，不含名称网址）；选「不加密」则全可见

我们不承诺的东西

这一节比上面所有功能都重要

如果只看一节，请看这节。下面是这个扩展现在做不到的事——写在这里，好让你带着准确的预期安装。

早期文档曾把 TapStack 称作「工作会话保险箱」。现已去掉「保险箱」——保险箱的心理契约是「东西丢了能找回来」，而本产品删除即物理清除、无回收站、不可恢复。定位词与实际行为必须一致。

—— TapStack README，关于命名

!删除即物理清除

没有回收站，没有撤销。删除前二次确认、「删除全部」强制确认并显示数量——但确认之后就是真的没了。

!口令丢了就解不开

WebDAV 加密是真的端到端：密钥由你的口令派生，我们和云盘服务商都拿不到。代价是口令没有找回入口——忘记后云盘上的数据将无法解密。

!不是实时协同

两台设备同时编辑同一会话，以最后保存一方为准。错峰使用不受影响。自动同步默认关闭，可选 5 / 10 / 30 / 60 分钟四档。

!只传你主动保存的

上传到云端的只有你主动保存过的标签页。不读浏览历史、不收集分析数据、不出售给第三方。

!云盘清单是明文的

用 WebDAV 时会话内容加密，但目录清单明文：服务商可见「多少会话、何时改过」，不含名称网址。

!OneTab 导入不含图标

OneTab 格式本身不含 favicon 与固定状态，导入后这两栏为空。其余内容有往返测试兜底，不截断不丢失。

常见问题

需要账号吗？数据存哪？

不需要。扩展没有账户体系，全部本地功能开箱即用；数据默认只保存在浏览器扩展存储中（并申请了 unlimitedStorage 以容纳重度用户）。要跨设备时，在设置里填你自己的 WebDAV 云盘地址，数据加密后只去那里，不经过我们的服务器。

删除的会话能找回来吗？

不能。v1.22.0 起删除即物理清除，没有回收站、不可恢复。删除前会有二次确认，「删除全部」强制确认并显示数量。请把删除当作不可逆操作。

和 OneTab 是什么关系？

支持 OneTab 文本格式双向导入导出，可以带着历史过来、也可以随时带着数据离开，不锁人。标题含竖线、本地文件地址等边界情况都有往返测试兜底。

两台电脑会互相覆盖吗？

下载采用「快照 → 下载 → 合并 → 校验 → 写入」，异常自动回滚；同一会话两边同时编辑时以最后保存一方整组为准。错峰使用不受影响。自动同步默认关闭，本地改动仍会照常上传。
